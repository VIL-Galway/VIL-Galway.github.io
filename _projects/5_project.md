## Overview
This project explores agentic AI systems for monitoring chronic stress.

## Funding
- Insight Research Ireland (Grant Number 12/RC/2289_P2)

## Duration
**Sep 2024 – Feb 2025**

## Team
- **PI:** Dr Ihsan Ullah  

## Researchers

## Description
The system uses multi-agent AI crews for adaptive stress monitoring.

- Autonomous decision-making  
- Real-time adaptation  
- Memory-based learning  
- Dynamic thresholding  
- Focus on ethics, bias, transparency, and safety
