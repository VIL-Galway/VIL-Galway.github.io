## Overview
This project explores transparency and explainability in AI systems using Semantic Web technologies.

## Description
The project transforms Model Cards, Data Cards, and Dataspace Cards into Linked Data representations.

- Introduces a linking vocabulary for card ontologies  
- Enables integration with knowledge graphs  
- Demonstrates use cases:
  - Bias detection  
  - Sentiment and emotion analysis
