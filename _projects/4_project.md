## Overview
AI4MI develops an augmented reality reading environment for radiologists.

## Description
The system integrates AI into radiology workflows without complex hospital integration.

- Works on Apple Vision Pro  
- Supports MRI, CT, and other modalities  
- Includes:
  - DICOM reader  
  - Automated parameter inference  
  - Interactive annotation tools  
  - Real-time volumetric rendering  
- Uses explainable AI and human-in-the-loop feedback
